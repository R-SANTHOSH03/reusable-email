# @santhosh_r/universal-email

Reusable SMTP email service for Node.js and TypeScript applications using Nodemailer.

## Features

- SMTP email sending
- Gmail SMTP support
- HTML email support
- Plain text email support
- Handlebars email templates
- Welcome email template
- OTP email template
- Password reset email template
- CC and BCC support
- Email attachments
- SMTP connection verification
- TypeScript support
- Node.js support
- NestJS support
- Express support
- Next.js backend support

## Installation

```bash
npm install @santhosh_r/universal-email
